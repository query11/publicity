|---|---|---|
| 0:00 | 开场痛点 | 动效标题：没有海外卡 / 绑卡被拒 / 代付不放心 → 3 步自助充值 |

## 成品

- `dist/plus-shop-recharge-demo-1080p.mp4`：成片（H.264 + AAC，响度 -16 LUFS）
- `dist/subtitles.srt`：字幕文件（可上传为 B 站 CC 字幕，或导入剪映）
- `dist/cover.png`：封面图（1920×1080）
- `发布文案与配音稿.md`：B 站标题 / 简介 / 标签建议，以及可直接用于 AI 配音的配音稿

## 关于金额和演示数据

- **不显示任何具体金额**：截图时在页面里对所有价格、合计、套餐标价，以及「200$」「100刀」这类字样做了模糊处理；示意画面里也不写金额。
- **不提交任何订单**：店铺页只操作到「确认订单」按钮为止，没有真正下单，订单查询也没有点击提交。
- **充值站使用演示数据**：截取 chong.cccard.uk 时，页面的所有接口请求都在本地拦截，用演示数据应答（`tools/capture_recharge.js`），没有把卡密、Session 或其他任何数据发到对方服务器。画面中的卡密 `PLUS-7XK2-M9QF-4TBA`、邮箱 `demo@example.com` 都是虚构的，Session 内容也做了模糊处理。
- 付款与发货两段是示意动画，画面右上角标有「示意画面 / 演示数据」，片尾有说明文字。

## 重新生成

依赖：Node 18+、Python 3（numpy）、ffmpeg、Playwright 自带的 Chromium。

```bash
cd video
npm install
bash tools/build.sh             # 用仓库里已有的截图素材渲染
bash tools/build.sh --capture   # 先重新截取真实页面（商品标题、销量等有变化时用）
```

调整画面：所有动画都写在 `stage/stage.js` 的时间轴里（镜头 `CAM`、屏幕切换 `SCREENS`、光标 `WCUR`、字幕 `CAPS`）。
用浏览器打开 `stage/index.html?play` 可以实时预览，`stage/index.html?t=60` 查看某一秒的画面。

背景音乐和音效由 `tools/audio.py` 程序合成，不涉及第三方版权素材，可替换成自己的 BGM。

## 目录
