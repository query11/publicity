## 成品

两个版本只有最后 18 秒不同：

- `dist/plus-pro-choose-1080p.mp4`：**无推广版，B 站发这个**。没有店铺名、二维码、链接、卖点。
- `dist/plus-pro-choose-shop-1080p.mp4`：带店铺版，片尾有店铺名、卖点和二维码。在 B 站属于商业推广，只有做了商业声明、绑定花火订单时才能用。
- `dist/subtitles.srt` / `dist/subtitles-shop.srt`：字幕 = 配音稿，可以导入剪映一键生成 AI 配音（步骤见发布文案）
- 成片都是 H.264 + AAC，响度 -18 LUFS，背景音乐偏小，给配音留空间
- `dist/cover.png`：封面图（1920×1080）
- `发布文案与配音稿.md`：B 站标题 / 简介（带章节时间）/ 标签 / 置顶评论 / 配音做法 / 发布前要确认的事

## 内容口径

- 画面、字幕、封面里只写「Plus / Pro」，不写 GPT 字样，不出现任何金额。
- 档位用店里和社区通用的「Pro 5x / Pro 20x」叫法。Pro 5x 的额度已经翻倍，现在约是 Plus 的 10 倍（名字没改），卡片上标了「已翻倍」；Pro 20x 约 20 倍。官方近几个月调整频繁，画面和口播都提示「以官网为准」。
- 5 种方式的优缺点都如实写，对比表里「直充自己的号」在隐私、售后两栏也标的是「一般」（要交登录凭证、售后看店铺质保），不把自家方式说成没有缺点。成品号店里也在卖，所以写的是适合谁、不适合谁，没有贬低。
- 不点名任何店铺；无推广版连自家店铺也不出现（上一条视频被 B 站判为未声明的商业推广并限流，违规位置是内容全程）。

## 重新生成

依赖：Node 18+、Python 3（numpy）、ffmpeg、Playwright 自带的 Chromium。

```bash
cd video-choose
npm install
bash tools/build.sh          # 无推广版
bash tools/build.sh --shop   # 带店铺版
```

改文案：所有字幕 / 配音句子都在 `stage/stage.js` 开头的 `SCRIPT` 里，**整条时间轴按这些句子自动排**（约 4.6 字 / 秒）。改一句话，后面的画面会跟着顺延，不用手动对时间。
卡片内容（三档、5 种方式、对比表、清单）也在 `stage/stage.js` 的 `TIERS` / `METHODS` / `TABLE` / `CHECKS` 里。

预览：浏览器打开 `stage/index.html?play` 实时播放，`stage/index.html?t=60` 看某一秒的画面；加 `shop`（如 `index.html?shop&play`）看带店铺版。

背景音乐和音效由 `tools/audio.py` 程序合成，不涉及第三方版权素材。
